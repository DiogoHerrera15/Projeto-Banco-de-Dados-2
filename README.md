# E-commerce DEFERENTE

Projeto desenvolvido para a disciplina de Banco de Dados II.

A proposta do sistema é simular um e-commerce simples, chamado **E-commerce DEFERENTE**, voltado para a venda de produtos de papelaria, escritório e acessórios básicos. A ideia foi escolher um contexto fácil de entender e que permitisse trabalhar os principais recursos pedidos no projeto, como clientes, vendedores, produtos, vendas, transportadoras, triggers, views, procedures e permissões de usuários.]
